## Descrição

Este repositório reúne as soluções dos exercícios práticos de Python desenvolvidos em sala de aula. Seu objetivo é servir como registro do aprendizado e consolidar os fundamentos da linguagem, contemplando atividades sobre:

Variáveis: declaração, manipulação e tipos de dados
Estruturas Condicionais: tomadas de decisão 
Laços de Repetição: estruturas de controle 
Listas: criação, iteração e manipulação de coleções

## Tecnologia Utilizada

Python v3.12.2

## Como Executar

 Pré-requisitos: Certifique-se de ter o Python instalado em seu sistema.
 Acessar o diretório: Abra o Prompt de Comando (CMD) ou Terminal na pasta onde o projeto está localizado.
 Executar o script: Rode o arquivo .py. desejado utilizando o comando: python "nome_do_arquivo"
